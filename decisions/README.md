# Public Decision Pointers

This directory contains concise public handles for program rulings that materially affect how the parent repository is interpreted.

These files are **pointers and summaries, not authority records**. Editing a file here cannot grant a model, agent, contributor, or application permission to act.

The authoritative decision record remains in the program's governed control plane and, where applicable, the owning repository or deployment evidence.

## Rule

Add a public pointer only when the decision is safe and useful to expose publicly. Do not copy private operational evidence, topology, credentials, planning state, or confidential decision context into this directory.
